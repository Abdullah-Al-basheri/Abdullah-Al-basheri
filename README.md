## 🚀 Featured Project

### 🧮 [CalcAA](https://github.com/Abdullah-Al-basheri/CalcAA), Arabic Scientific Calculator

An Arabic educational calculator with its own math display engine. It follows the full journey from a visual expression, to a parser, to the final result, so students can see math written the way they learn it.

**Focus:** expression parsing · mathematical logic engine · system architecture
